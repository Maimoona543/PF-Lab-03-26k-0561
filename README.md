## Introduction

This repository contains my work for Lab 03 of the Programming Fundamentals (CL1002) course. The lab focuses on getting comfortable with Git/GitHub workflows (branches, commits, pull requests) and on writing basic C programs covering data types, format specifiers, and input/output functions.

## Objectives

1. Create and configure a GitHub repository correctly.
2. Practice branching, committing, and opening/merging pull requests.
3. Document C programming concepts using Markdown.
4. Write C programs demonstrating variables, data types, and format specifiers.
5. Practice using `scanf()`, `printf()`, `getchar()`, and `putchar()`.
6. Understand precision formatting for floating-point output.

## C Topics Covered in Lab 03

- Data types (int, float, double, char, bool, void)
- Format specifiers (%d, %f, %c, %s, etc.)
- Input/output functions (scanf, printf, getchar, putchar, fgets, puts)
- Escape sequences (\n, \t, \\, \", \')
- Precision formatting for floats and doubles
